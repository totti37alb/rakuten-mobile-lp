# 【2026年6月版】楽天モバイルのエリア・電波を徹底検証

「楽天モバイルは電波が悪い」——それ、2023年以前の話です。

2024年6月のプラチナバンド（700MHz帯）運用開始以降、楽天モバイルの電波状況は大きく変わりました。2026年6月現在の実態を、数字と場所別データでまとめます。

## 過去と現在を比較した一覧表

| 観点 | 2020〜2023年 | 2026年6月現在 |
|------|------------|------------|
| プラチナバンド | 非対応 | 2024年6月運用開始・順次拡大中 |
| 人口カバー率 | 約95〜96% | **99.9%達成** |
| 基地局数 | 数千〜2万局台 | **約60,000局**（2025年9月時点） |
| 都内地下鉄（東京メトロ・都営） | 未対応駅多数 | 2026年3月末で**約95%完了**、7月に全区間完了予定 |
| 私鉄地下区間 | 一部未対応 | **2025年12月時点で100%完了** |
| auパートナー回線 | 広範囲でローミング | 2026年9月30日終了予定→自社回線へ完全移行 |
| 衛星通信 | なし | **2026年Q4（10〜12月）商用開始予定** |

## プラチナバンドで何が変わったか

プラチナバンド（700MHz帯、Band 28）は、低周波数ゆえに障害物を「回り込む」性質を持ちます。ドコモ・au・ソフトバンクが長年使い続けてきた帯域で、楽天モバイルが割当を受けたのは2023年10月、運用開始は2024年6月27日（東京都から順次）です。

**効果が特に出やすい場所：**

- 高層ビルの中・低層階の奥まった部屋
- 地下街・地下鉄構内
- コンクリート壁が厚い古いマンション
- 山の谷間や丘の影になるエリア

2026年3月時点で**約10,661局の基地局設置計画**が進行中。楽天モバイル社内のユーザーアンケート（2025年11〜12月）では、**83.2%のユーザーが通信品質の改善を実感**と回答しています（2024年12月比で+5.4ポイント）。

## 地下鉄・地下空間の状況（都市別）

2026年2月に「つながりやすさ強化宣言2026」を発表。地下空間の通信帯域を**5MHz→20MHz（約4倍）**に拡張する工事を進めています。

| エリア | 2025年12月時点 | 完了目標 |
|--------|-------------|--------|
| 東急・小田急・京成・りんかい線・京王・相鉄・東京モノレール等（私鉄地下区間） | **100%完了済** | 完了 |
| 東京メトロ・都営地下鉄 | 約95%完了 | **2026年7月 全区間完了予定** |
| 札幌市営地下鉄 | 65%完了 | **2026年6月** |
| 福岡市営地下鉄 | 67%完了 | 2027年4月 |
| 名古屋市営地下鉄 | 25%完了 | 2027年4月 |
| 大阪メトロ | 25%完了 | 2027年12月 |

首都圏の私鉄地下区間は既に対応済み。東京メトロ・都営も2026年7月に完了する見通しで、**「地下鉄は使えない」という弱点は首都圏ではほぼ解消済み**といえます。

## 主要競馬場での状況（2026年6月）

競馬場は「屋外の大型施設」という点では基本的に問題なく使えます。ただし観客が密集するGI開催日は全社で混雑します。

| 競馬場 | エリア状況 | 注意点 |
|--------|---------|-------|
| **東京競馬場**（府中市） | ◎ 自社5G/LTE + プラチナバンド展開済み | ジャパンカップ・天皇賞など大型開催の混雑時はパケ詰まりの可能性あり |
| **中山競馬場**（船橋市） | ○ LTE・プラチナバンド対応 | スタンド下層・内馬場トンネル付近は弱い場合あり |
| **阪神競馬場**（宝塚市） | ○ ほぼ全エリア対応 | 大阪神戸エリアはプラチナバンド展開済み |
| **京都競馬場**（京都市） | ○ 対応エリア | リニューアル後の屋内エリアは要確認 |
| **中京競馬場**（豊明市） | △ Band 3主体 | プラチナバンド展開中、屋内席は弱い場合あり |
| **小倉競馬場**（北九州市） | △ 改善途上 | 福岡エリアのプラチナバンド展開継続中 |

**tottiのリアルな体感：** 東京競馬場でDAZNのハイライト確認やX（旧Twitter）への投稿は問題なくできています。ただし有馬記念・ジャパンカップのような超大型開催は全キャリアでつながりにくくなることがあるので、直前の速報確認は早めに済ませておくのがオススメです。

## まだ電波が弱い場所（正直に書きます）

「繋がりやすさが改善した」は本当ですが、すべてが解決したわけではありません。

**依然として弱い可能性がある場所：**

- 地方の郊外・農村部（プラチナバンド未展開エリア）
- 山間部・離島（au パートナー回線終了後に要注意）
- 古い厚いコンクリート造のビル・マンション上層部内側
- ターミナル駅（新宿・渋谷・東京）のラッシュ時混雑
- 大阪メトロ・名古屋・福岡の地下（2027年まで工事継続中）

**特に注意したいのは2026年9月以降。** KDDIとのauパートナー回線が2026年9月30日に終了予定で、それ以降は楽天モバイル自社回線のみになります。山間部や地方をよく使う方は、**9月までにエリアマップで確認**しておくことを強くおすすめします。

## 速度データ：他社との比較（2026年3月 MMD研究所調査）

| キャリア | 東京・大阪の主要地点 ダウンロード速度（中央値） |
|---------|-------------------------------|
| ソフトバンク | **244.5 Mbps** |
| au | 189.0 Mbps |
| ドコモ | 174.5 Mbps |
| **楽天モバイル** | 131.5 Mbps |

平均ダウンロード速度（みんそく計測）：楽天モバイル **86.72 Mbps** / Ping値 **49.47 ms**

**正直に言います。** 速度は3キャリアに比べると現状は見劣りします。ただ、YouTubeやDAZN視聴、SNS投稿、競馬の実況確認といった用途では、86 Mbpsでも実用上まったく問題ありません。速度が重要になるのは大容量ファイルのダウンロードや超高解像度ゲームくらいです。

楽天モバイルは2026年に**2,000億円超をネットワーク強化に投資**する計画を発表。5G SA（スタンドアロン）化も2026年内に開始予定で、速度面でも改善が見込まれています。

## 2026年Q4予定：衛星通信「Rakuten最強衛星サービス」

米国のAST SpaceMobileと提携し、**普通のスマートフォンに直接届く衛星通信サービス**を2026年第4四半期（10〜12月）に商用開始予定です。

2025年4月には日本国内で低軌道衛星と市販スマホによるビデオ通話の実証実験に成功しています。

これが実現すると、山間部・離島・海上など地上の基地局が届かないエリアでも繋がるようになります。今まで「競馬場遠征で地方の山の中を通ると圏外」という場面も解消される見込みです。
